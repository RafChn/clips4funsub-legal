Clipper – Privacy Policy

Effective date: October 18, 2026 · Operated by Rafael Chacón

Clipper is a private, single-user command-line tool that the owner of the YouTube channel Clips4funSub runs on their own computer to upload short clips to that channel. It is not distributed to the public and has no other users. This policy explains what data Clipper uses and how.

YouTube API Services

Clipper uses YouTube API Services. By using Clipper you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data Clipper accesses

  • Permission to upload videos to the authorizing account's YouTube channel (youtube.upload).
  • Read-only access to that same channel's own uploads (youtube.readonly), used only to check whether a clip was already uploaded so it is never uploaded twice.

Clipper does not access data about any other user, channel, comment, subscriber or analytics.

Data Clipper stores

  • The Google OAuth token, stored only on the owner's computer.
  • For each uploaded clip: the YouTube video ID, URL, privacy status and upload time, stored in a local file on the owner's computer.

How the data is used and shared

The data is used only to upload the owner's clips and to avoid duplicate uploads. It is not sold, shared with third parties, used for advertising, or sent anywhere other than Google's OAuth and YouTube API endpoints. Clipper uses no cookies, analytics or tracking.

Retention and deletion

Data stays on the owner's computer until the owner deletes it. You can revoke Clipper's access at any time from Google security settings. Deleting Clipper's local token and state files removes all data it stored.
